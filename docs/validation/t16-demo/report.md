## 인프라 구성
- BE: Node/Fastify, 8000, /health, 100m·128Mi 요청·256Mi 한도, replicas 1.
- FE: nginx, 3000, /, 50m·32Mi 요청·64Mi 한도, replicas 1.
- test/prod 및 Blue-Green 배수 2를 계산에 포함한다. AWS t3.medium 3대, 공유 PostgreSQL RDS 1개를 유지한다.

## 확장 계획
합계 수용량은 ADR-0014의 가정으로만 검사했다. 실제 파드 배치·성능·노드 여유는 미검증이며 replicas 변화로 노드 수를 자동 변경하지 않는다.

## 필요한 코드 수정
이번 비용 검증을 위한 앱 코드 수정은 없다.

## 보안 · 규제
compliance: regulated를 보존한다. 운영 배포는 사람 승인 경로를 따른다. 이 보고서 생성은 배포 승인이 아니다.

## 가정
ADR-0014의 월 730시간과 데모 예상 사용량을 적용했다. 실제 청구·운영 통계가 아니다. 무료 한도와 계정 기존 사용량은 미산정이다. AWS 유료 커스텀 메트릭은 데모 견적 범위 밖이다. DNS·백업·추가 네트워크 텔레메트리·온프레미스 운영비는 별도 확인해야 한다.

## 예산 초과 시 절감 대안
노드 3대·DB를 유지하며 외부 공개 앱 환경을 하나로 줄이는 시나리오를 비교했다. ALB 3→2개, 공인 IPv4 가정 7→5개다. 같은 월 트래픽을 ALB별로 재배분했다. 공개 접근 범위가 달라지므로 실제 적용 전 test/prod 접근 요구·운영·규제를 확인해야 한다. 인프라 변경은 실행하지 않았다.
